How to Convert to PNG:

  1. Online Method (Recommended):
    • Go to svgtopng.com
    • Upload the ratio-icon.svg file
    • Set output size to 128×128 pixels
    • Download the PNG file
  2. Alternative - Right-click method:
    • Right-click on one of the SVG icons above
    • Select "Save image as..." or "Copy image"
    • Note: This may not give you exactly 128×128, so the online converter is preferred
  3. Using Photoshop/GIMP:
    • Open the SVG file in your graphics editor
    • Set canvas size to 128×128 pixels
    • Export as PNG
